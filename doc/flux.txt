NAME
 flux - light command line download accelerator

SYNOPSIS
 flux [OPTIONS] url1 [url2] [url...]

DESCRIPTION
 Hyperflux is a program that downloads a file from a FTP or HTTP server through multiple connection.
 Each connection downloads its own part of the file.

 Unlike most other programs, Hyperflux downloads all the data directly to the destination file.
 It saves some time at the end because the program does not have to
 concatenate all the downloaded parts.

 Hyperflux supports HTTP, HTTPS, FTP and FTPS protocols.

OPTIONS
 One argument is required, the URL to the file you want to download. When downloading from FTP,
 the filename may contain wildcards and the program will try to resolve the full filename. Multiple
 mirror URLs to an identical file can be specified as well and the program will use all those URLs
 for the download.

 Please note that the program does not check whether the files are equal.

 A single URL argument may instead contain a range or list pattern, in which case it expands into
 several separate downloads run one after another, each still accelerated with multiple connections.
 See URL EXPANSION below. Multiple distinct URL arguments are always treated as mirrors of one file,
 not as separate downloads.

 Other options:

 --max-speed=x, -s x  Specify a speed (bytes per second) to try to keep the average speed around this
                      speed. This is useful if you do not want the program to suck up all of your
                      bandwidth.

 --num-connections=x, -n x  Specify an alternative number of connections.

 --max-redirect=x  Specify an alternative number of redirections to follow when connecting to the
                   server (default is 20).

 --output=x, -o x  Downloaded data will be put in a local file with the same name, unless you specify
                   a different name using this option. You can specify a directory as well, the program
                   will append the filename. When the URL expands into several downloads (see URL
                   EXPANSION), a directory receives each per-URL name, and a "#N" placeholder in the
                   name is replaced by the value the Nth pattern took. A plain single filename is
                   refused when the expansion yields more than one URL, as it would clobber itself.

 --search[=x], -S[x]  Hyperflux can do a search for mirrors using the filesearching.com search engine. This
                      search will be done if you use this option. You can specify how many different
                      mirrors should be used for the download as well. The search for mirrors can be
                      time-consuming because the program tests every server's speed, and it checks
                      whether the file's still available.

 --ipv6, -6  Use the IPv6 protocol only when connecting to the host.

 --ipv4, -4  Use the IPv4 protocol only when connecting to the host.

 --no-proxy, -N  Do not use any proxy server to download the file. Not possible when a transparent proxy
                 is active somewhere, of course.

 --insecure, -k  Do not verify the SSL certificate. Only use this if you are getting certificate errors
                 and you are sure of the sites authenticity.

 --no-clobber, -c Skip download if a file with the same name already exists in the current folder and no state file is found.

 --verbose, -v  Show more status messages. Use it more than once to see more details.

 --quiet, -q  No output to stdout.

 --alternate, -a  This will show an alternate progress indicator. A bar displays the progress and status
                  of the different threads, along with current speed and an estimate for the remaining
                  download time.

 --progress, -p    Print simple percentages instead of progress bar (0-100).
 --header=x, -H x  Add an additional HTTP header. This option should be in the form "Header: Value". See
                   RFC 2616 section 4.2 and 14 for details on the format and standardized headers.

 --user-agent=x, -U x  Set the HTTP user agent to use. Some websites serve different content based upon
                       this parameter. The default value will include "Hyperflux", its version and the platform.

 --help, -h  A brief summary of all the options.

 --timeout=x, -T x  Set I/O and connection timeout

 --version, -V  Get version information.

NOTE
 Long (double dash) options are supported only if your platform knows about the getopt_long call. If it
 does not (like *BSD), only the short options can be used.

URL EXPANSION
 A single URL argument may contain brace or bracket patterns. Hyperflux expands such a URL into several
 separate downloads, run one after another, each still accelerated with multiple connections. This is
 distinct from passing several URL arguments, which are always treated as mirrors of one file.

 The following pattern syntaxes are supported:

 {a,b,c}  A list. Each comma-separated item produces one URL.

 {N..M}, {N..M..S}  A bash-style numeric range from N to M. It may descend (when N is greater than M),
                    and an optional step S sets the increment. When the bounds are zero-padded, the
                    values keep the width of the wider token.

 {a..z}  A bash-style single-character range.

 [N-M], [N-M:S]  A curl-style numeric range from N to M, ascending only, with an optional step S.

 [a-z], [a-z:S]  A curl-style single-character range, with an optional step S.

 A group is expanded only when it fully matches one of the forms above; anything else is left
 untouched, so IPv6 literals and CGI parameters are not affected.

 A single expansion may produce at most 10000 URLs; beyond that Hyperflux refuses to run.

 Take care with shell quoting. Quote the URL with single quotes so the shell does not expand the
 braces itself; an unquoted {01..12} is expanded by the shell into separate arguments, which Hyperflux
 would then treat as mirrors. Bracket forms such as [01-12] usually survive unquoted.

RETURN VALUE
 The program returns 0 when the download was successful, 1 if something really went wrong and 2 if the
 download was interrupted. If something else comes back, it must be a bug.

EXAMPLES
 The trivial usage to download a file is similar to:

    $ flux http://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-9.1.0-amd64-netinst.iso

    $ flux ftp://ftp.nl.kernel.org/pub/linux/kernel/v2.2/linux-2.2.20.tar.bz2

 This will use the Belgian, Dutch, English and German kernel.org mirrors to download a Linux 2.4.17
 kernel image.

    $ flux ftp://ftp.{be,nl,uk,de}.kernel.org/pub/linux/kernel/v2.4/linux-2.4.17.tar.bz2

 This will do a search for the linux-2.4.17.tar.bz2 file on filesearching.com and it'll use the four (if possible)
 fastest mirrors for the download (possibly including ftp.kernel.org).

    $ flux -S4 ftp://ftp.kernel.org/pub/linux/kernel/v2.4/linux-2.4.17.tar.bz2

 This expands one URL into twelve separate downloads, video01.mp4 through video12.mp4 (see URL
 EXPANSION). The URL is quoted so the shell leaves the brackets for Hyperflux.

    $ flux 'http://example.com/video[01-12].mp4'

 This downloads v1.mp4 through v5.mp4 and writes them as clip1.mp4 through clip5.mp4, the "#1"
 placeholder taking the value of the first (and only) pattern.

    $ flux -o 'clip#1.mp4' 'http://example.com/v[1-5].mp4'

FILES
 /etc/fluxrc  System-wide configuration file.

 ~/.fluxrc  Personal configuration file.

 These files are not documented in a manpage, but the example file which comes with the program contains
 enough information. The position of the system-wide configuration file might be different. In source code this
 example file is at doc/ directory. It's generally installed under /usr/share/doc/flux/examples/, or the
 equivalent for your system.
